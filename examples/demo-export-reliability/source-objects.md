# Source Objects

Every object used as evidence in this case. All are committed files in this
repository, so they are reproducible without credentials.

- `examples/local-sources/exports_weekly.csv` — weekly export counts and queue
  minutes, 2026-01-05 to 2026-04-06 (accessed 2026-08-17)
- `examples/local-sources/context/change-log.md` — operational notes, including
  the 2026-03-09 scheduler change (accessed 2026-08-17)
- `examples/local-sources/context/metric-definitions.md` — column meanings and
  the success-rate definition (accessed 2026-08-17)
